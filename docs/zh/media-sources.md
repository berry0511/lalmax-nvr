# 媒体接入

「媒体接入」是 NVR Web UI 中配置媒体输入的统一入口。它汇总摄像头与设备、直播源地址、IPTV 播放列表、Emby 影音库和编码器推流，并提供各来源的状态和管理入口。

从侧栏打开 **媒体接入**。可用的快捷路由包括：

- 总览：`#/media-sources`
- IPTV：`#/media-sources?tab=iptv`
- Emby：`#/media-sources?tab=emby`
- 摄像头和设备：`#/devices`
- 直播源或编码器推流：`#/streams`

旧链接 `#/iptv` 和 `#/emby` 仍会打开媒体接入页面中对应的配置页。

## 来源类型

| 类型 | 用途 | 配置入口 |
|------|------|----------|
| 摄像头与设备 | 连接 ONVIF、RTSP、国标及其他已支持设备 | 添加接入 → 摄像头或设备；设备页也可直接添加 |
| 直播源地址 | 从 RTSP、RTMP、HTTP-FLV 等支持的地址拉流 | 添加接入 → 直播源地址 |
| IPTV 播放列表 | 导入 M3U，再选择要纳管的直播频道 | 添加接入 → IPTV 播放列表 |
| Emby 影音库 | 浏览 Emby 电影或剧集并添加为 NVR 媒体项 | 添加接入 → Emby 影音库 |
| 编码器推流 | 创建流并将 NVR 推流地址配置到编码器 | 添加接入 → 编码器推流 |

Jellyfin、Plex 和本地 / NAS 文件目前尚未提供配置能力，页面会标为后续接入类型。

## 理解来源、内容和运行态

- **来源配置**描述 NVR 从哪里获取媒体，例如 Emby 服务器或 M3U 播放列表。
- **内容项**是来源里的可管理媒体，例如 IPTV 频道或 Emby 电影 / 剧集。
- **运行流**表示当前已发布、正在推拉或可供播放的流，可在流管理页查看。
- **录像计划**决定哪些流需要持续或按计划录像，在录像计划页配置。

总览页汇总来源状态和数量；它不会把来源本身误作一个运行中的直播流。

## 选择来源类型

| 来源 | 用途 | 添加方式 | 播放和发布 |
|------|------|----------|------------|
| IPTV | 管理 M3U 播放列表中的直播频道 | 导入 M3U URL 或文本，检测后选择频道纳管 | 可在浏览器经 NVR 同源 HLS 代理直播放；启用发布或创建录像计划时，NVR 才启动服务端拉流 |
| Emby 影音库 | 将 Emby 媒体库中的电影或剧集作为 NVR 直播源 | 配置 Emby 服务，搜索媒体项并添加到 NVR | 发布时由 NVR 从 Emby 获取 HLS；播放结束后流下线，或按设置自动循环 |

两者都可以发布为 NVR 流，并在流管理和支持的播放协议中使用。IPTV 频道与 Emby 媒体项都有稳定的 `stream_id`，可用于查看流详情；IPTV 还可以在录像计划中按 `stream_id` 设置录像。

## IPTV 操作

1. 打开 **媒体接入 → IPTV 播放列表**，导入 M3U URL 或粘贴 `#EXTM3U` 文本。
2. 查看频道检测结果，选择需要纳管的频道。
3. 点击频道可通过浏览器播放；若要通过 NVR 的 RTSP、HTTP-FLV、HLS、WebRTC 等协议播放，启用频道的**发布**。
4. 若要录像，在录像计划中使用该频道的 `stream_id` 创建计划。

浏览器直播放走 NVR 同源代理，不依赖源站 CORS。发布和录像共享服务端 HLS 拉流；详情见 [IPTV 指南](iptv.md)。

## Emby 操作

1. 打开 **媒体接入 → Emby 影音库**，填写 Emby 服务地址、用户 ID 和访问令牌并连接。
2. 搜索电影或剧集，将媒体项添加到 NVR。
3. 按需启用**发布**；播放结束后流会下线。勾选**片尾自动循环**后，NVR 会重新创建播放会话并从头播放。

Emby 服务必须能从 NVR 主机访问，且 Emby 输出需满足 NVR 支持的 HLS 编码要求。配置和生命周期详见 [Emby 影音库指南](emby.md)。

## 接口与配置

Web 入口统一，服务端仍按来源类型使用独立 API。IPTV API 见 [API 参考中的 IPTV 部分](api-reference.md#iptv)，Emby API 见 [Emby 部分](api-reference.md#emby)。敏感字段的加密密钥配置方式见 [Emby 影音库指南](emby.md#配置)。
